# Startup

Curated founder operating system for skills.sh.

> **Note**: The main skill definition is located at [skills/startup/SKILL.md](skills/startup/SKILL.md). This root SKILL.md is maintained for skills.sh compatibility.

Install this bundle when you want the full startup founder stack in one command instead of separate skill installs.

## Installation

```bash
npx skills add justinedevs/collection/startup
```

## What's Included

When you install `startup`, all files below are available automatically:

- `skills/startup/SKILL.md`
- `skills/startup/startup-manager/`
- `skills/startup/founder-foundation/`
- `skills/startup/value-validation/`
- `skills/startup/mvp-engine/`
- `skills/startup/fundraising-kit/`
- `skills/startup/gtm-launch/`
- `skills/startup/growth-engine/`
- `skills/startup/founder-ops/`
