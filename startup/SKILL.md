# Startup

Curated founder operating system for skills.sh.

> **Note**: The main skill definition is located at [.claude/skills/startup/SKILL.md](.claude/skills/startup/SKILL.md). This root SKILL.md is maintained for skills.sh compatibility.

Install this bundle when you want the full startup founder stack in one command instead of separate skill installs.

## Installation

```bash
npx skills add justinedevs/collection/startup
```

## What's Included

When you install `startup`, all files below are available automatically:

- `.claude/skills/startup/SKILL.md`
- `.claude/skills/startup/startup-manager/`
- `.claude/skills/startup/founder-foundation/`
- `.claude/skills/startup/value-validation/`
- `.claude/skills/startup/mvp-engine/`
- `.claude/skills/startup/fundraising-kit/`
- `.claude/skills/startup/gtm-launch/`
- `.claude/skills/startup/growth-engine/`
- `.claude/skills/startup/founder-ops/`
